## 🛠️ Prerequisites & Setup

Ensure you have Flutter and Dart installed on your system:

```bash
# Check Flutter installation
flutter doctor
```

### Running Any Assignment

Navigate to any assignment directory and run:

```bash
# Navigate to project folder (example: Assignment 4)
cd "Flutter Assignment 4"

# Get dependencies
flutter pub get

# Run on available device or simulator
flutter run
```
